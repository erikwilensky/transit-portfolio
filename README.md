# NIST Transit Portfolio — pitch demo

A static, clickable demo of NIST Transit Portfolio: each student's journey drawn as a metro map,
fed (in mock) by school systems and re-presented for different audiences. No backend, no
logins, no external calls. All students, teachers and records are fictional.

## Run it

```sh
npm install
npm run dev        # local dev server
npm run build      # writes dist/ (plain HTML, CSS, JS)
npx serve dist     # quick static server, or point Apache / nginx / Caddy at dist/
```

`dist/` uses relative paths (`base: './'`), so it works from any folder or URL path.

## Screens

1. **Student map** — full metro map, tap a station for evidence, reflection and verification.
2. **Presentation studio** — each audience gets its own format: General (profile), University
   (narrative), Specific university ("why this course" statement), Employer (CV), Scholarship
   (impact timeline). The metro map is optional here. Skill tiers: Template, Builder, Code.
3. **Shared view** — what an external viewer sees from a share link.
4. **Integrations** — mock adapters; *Sync* pulls items into the student's inbox, and the
   student chooses a line for each one (or skips it) before it joins the map.
5. **Advisor** — cohort grid of mini-maps with reflection flags.

The **Pitch tour** button (top right) jumps straight to each scripted moment.

## Where things live

```
data/            mock JSON in the shape of the data model (generated by scripts/seed.mjs)
src/api.js       the only module that reads /data; applies visibility and lens rules
src/layout/      metroLayout.js: time → x (term columns), line → lane, interchange bends
src/components/  MetroMap, StationPanel, LensSwitcher, TierToggle, PresentationView,
                 CodeView, IntegrationsPanel, AdvisorGrid, SharedView, Studio
src/themes/      presentation themes and layouts
```

To change the mock data, edit `scripts/seed.mjs` and run `npm run seed`. Evidence images are
flat SVG illustrations drawn by `scripts/illustrations.mjs` into `public/evidence/`.
Synced items live in memory only; reload to reset the demo.

## Custom audience

The Custom audience opens a page builder (`src/custom/`). Students start from one of eight themes or set their own colours, font pair, corner radius, background pattern, card style, spacing and page width. They add any of 13 blocks (hero, text, metro map, feature station, stations, gallery, quote, stats, timeline, lines, skills, next stops, divider), drag them into place, drag a block's edge to resize it on a 6-column grid, and edit their own text in place. Undo and redo are built in. Blocks reference verified stations by id and never edit them, and the public view applies the same visibility rules.

## Brand colours (NIST Brandbook 2024)

The app uses navy `#002855` and the six secondary colours `#4F529B`, `#78D5E1`, `#008A60`, `#E73C3E`, `#FF8F1C` and `#FFB81C`. The tertiary `#45C4C9` is for internal documents only and is not used.

| Line | Colour | Pattern |
|---|---|---|
| Science | `#4F529B` | solid |
| Computing | `#78D5E1` | solid |
| Environment | `#008A60` | solid |
| Service | `#E73C3E` | solid |
| Music | `#FF8F1C` | solid |
| Art | `#FFB81C` | solid |
| Design | `#78D5E1` | cased (light centre) |
| Languages | `#4F529B` | cased |
| Sport | `#FFB81C` | cased |

Exceptions, kept on purpose:

- **Sub-lines** (a student's branch, such as Data Science under Science) use a tint of the parent colour: `#8D8FBE`, `#4DAD8C`, `#EE7B7D` and `#FFB160`. Under the light sky and gold, a tint would vanish on white, so those branches use a deeper shade instead (`#3FA9BC`, `#E0A010`).
- **Neutrals** for text, rules and surfaces (greys and the dark-mode backgrounds) are not brand colours and are not listed.
- **Charts** use the validated `--dv1..3` series colours from the palette above.
- **Custom page themes** (Forest, Rose and so on) belong to students and may be off-brand. A NIST theme is offered.
